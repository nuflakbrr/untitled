# TC330 — Anonymous Admin Protection

## Tujuan
Memastikan pengguna anonim tidak dapat melihat manajemen pengguna tenant.

## Prasyarat
Browser tidak memiliki sesi login.

## Langkah
1. Buka URL manajemen Pengguna tenant root secara langsung.

## Hasil yang Diharapkan
Pengguna diarahkan ke halaman login.
