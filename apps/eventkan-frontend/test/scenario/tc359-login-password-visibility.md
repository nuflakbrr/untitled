# TC359 — Visibilitas Password Login

## Tujuan
Memastikan password dapat ditampilkan dengan kontrol yang aksesibel.

## Prasyarat
Halaman login dapat dibuka.

## Langkah
1. Buka login.
2. Tekan tombol Tampilkan password.

## Hasil yang Diharapkan
Tipe input berubah dari `password` menjadi `text` dan label tombol menjadi Sembunyikan password.
