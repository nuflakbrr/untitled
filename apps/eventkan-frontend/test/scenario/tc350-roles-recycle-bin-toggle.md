# TC350 — Toggle Recycle Bin Jabatan

## Tujuan
Memastikan modul Jabatan mendukung perpindahan data aktif dan recycle bin.

## Prasyarat
Root superadmin terautentikasi pada tenant root.

## Langkah
1. Buka Jabatan.
2. Tekan Recycle bin lalu Data aktif.

## Hasil yang Diharapkan
Kedua tab dapat dipilih tanpa error UI.
