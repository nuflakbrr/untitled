# TC349 — Toggle Recycle Bin Organisasi

## Tujuan
Memastikan pengguna dapat berpindah antara data aktif dan recycle bin tenant.

## Prasyarat
Root superadmin terautentikasi pada tenant root.

## Langkah
1. Buka Organisasi.
2. Tekan Recycle bin.
3. Tekan Data aktif.

## Hasil yang Diharapkan
Kedua kontrol tersedia dan dapat digunakan bergantian tanpa kehilangan halaman.
