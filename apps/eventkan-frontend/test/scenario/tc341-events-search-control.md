# TC341 — Pencarian Event

## Tujuan
Memastikan tabel event memiliki input pencarian khusus dan menerima kata kunci.

## Prasyarat
Root superadmin terautentikasi pada tenant root.

## Langkah
1. Buka daftar Event.
2. Isi pencarian dengan kata kunci yang tidak ada.

## Hasil yang Diharapkan
Input `Cari event...` terlihat dan mempertahankan nilai yang dimasukkan.
