# TC342 — Pencarian Kategori Event

## Tujuan
Memastikan tabel kategori event memiliki pencarian yang terisolasi dari modul lain.

## Prasyarat
Root superadmin terautentikasi pada tenant root.

## Langkah
1. Buka daftar Kategori Event.
2. Isi pencarian dengan nilai yang tidak ada.

## Hasil yang Diharapkan
Input `Cari kategori...` terlihat dan menerima nilai pengguna.
