# TC351 — Toggle Recycle Bin Pengguna

## Tujuan
Memastikan modul Pengguna mendukung perpindahan data aktif dan recycle bin.

## Prasyarat
Root superadmin terautentikasi pada tenant root.

## Langkah
1. Buka Pengguna.
2. Tekan Recycle bin lalu Data aktif.

## Hasil yang Diharapkan
Kedua tab dapat dipilih tanpa error UI.
