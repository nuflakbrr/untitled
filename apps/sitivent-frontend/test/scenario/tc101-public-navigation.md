# Test Case: Public Navigation (TC101)
Memastikan menu publik utama dapat dibuka dan tidak menghasilkan halaman kosong atau error.

## Langkah
1. Buka `/`, `/events`, `/articles`, dan `/gallery`.
2. Pastikan dokumen memiliki konten dan setiap navigasi selesai.

## Hasil yang Diharapkan
Semua halaman publik merender konten tanpa status error.
