# TC319 — Root Dashboard Route

## Tujuan
Memastikan akun root superadmin masuk ke dashboard tenant root yang benar.

## Prasyarat
Data seed aktif dan kredensial root tersedia melalui konfigurasi E2E.

## Langkah
1. Login sebagai root superadmin.
2. Tunggu navigasi selesai.

## Hasil yang Diharapkan
URL berakhir di dashboard tenant root dan navigasi Dashboard terlihat.
