# TC347 — Pencarian Testimoni

## Tujuan
Memastikan daftar testimoni dapat difilter lewat input pencarian.

## Prasyarat
Root superadmin terautentikasi pada tenant root.

## Langkah
1. Buka daftar Testimoni.
2. Isi pencarian dengan nilai yang tidak ada.

## Hasil yang Diharapkan
Input pencarian testimoni terlihat dan menerima nilai pengguna.
