# Test Case: Mobile Responsive Layout (TC102)
Memastikan halaman publik tetap dapat digunakan pada viewport smartphone.

## Langkah
1. Buka halaman event dengan viewport 390x844.
2. Pastikan body terlihat dan tidak melebar secara horizontal.

## Hasil yang Diharapkan
Konten tampil di viewport mobile tanpa overflow horizontal yang signifikan.
